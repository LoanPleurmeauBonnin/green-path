Limites de la recherche :
- **Composition visuelle NON VERIFIEE** : aucune image n'a ete regardee (seulement titres, descriptions et categories Commons). Verifier a l'oeil que la prise de vue est bien frontale/lisible avant pixelisation.
- **Droits de panorama** : aucun modele de restriction (FoP, marque) affiche sur les pages lues. Les edifices sont anciens (chateau, cathedrale, serres de 1895/1897, maisons du XVe s.). Aucune oeuvre contemporaine protegee n'est a priori au premier plan : A VERIFIER sur l'image.

Les elements patrimoniaux choisis pour Jardin des Plantes et Bouffay s'appuient donc sur Commons (descriptions + base Merimee citee sur la page) et sur des sources secondaires : **A VERIFIER sur Patrimonia**.
- Format d'attribution propose : `Auteur, licence, via Wikimedia Commons` + lien vers la page File: et vers la licence. Pour CC BY-SA : indiquer les modifications (pixelisation) ; l'oeuvre derivee doit rester sous CC BY-SA (partage a l'identique) : **point a trancher pour le jeu / les assets pixel art**.

## 4. Quartier du Bouffay

**Element patrimonial propose : la maison du XVe s., 7 rue de la Juiverie** (monument historique inscrit, base Merimee **PA00108753**, d'apres la page Commons #1). Sources secondaires (Lonely Planet, Le Voyage a Nantes) la citent parmi les maisons medievales a pans de bois du quartier. Une source (Ryo) conteste la datation medievale des maisons de la rue : **A VERIFIER sur Nantes Patrimonia** (inaccessible). Alternatives non explorees : maisons de la place du Change / rue Bossuet : A VERIFIER.
