# Test croisé silencieux — Green Path

> **À remplir par l'équipe après le test.** Aucune observation n'est inventée dans ce document : tant que les cases ci-dessous sont vides, le test croisé n'a pas eu lieu.

## Protocole (mardi 10 novembre, J2)
1. Une personne **extérieure au projet** (binôme ou camarade) ouvre https://green-path-game.vercel.app sans explication.
2. Elle joue **5 à 10 minutes** ; l'équipe **ne parle pas, ne montre rien, ne corrige rien** et note seulement ce qu'elle observe.
3. À la fin, trois questions : *Qu'as-tu compris du jeu ? Qu'est-ce qui t'a bloqué ou surpris ? Qu'as-tu retenu du lieu ?*
4. Les changements décidés après le test vont dans le carnet de bord (itération post-test), avec la date.
